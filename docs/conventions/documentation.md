## Правило

Документ `docs/` — атом одного из четырёх видов. Вид задаёт папка, поле во frontmatter его
не дублирует.

| Папка | Вид | Что несёт | Чего не несёт |
|---|---|---|---|
| `docs/conventions/` | Конвенция | Правило работы или кода и короткое «почему» | Историю, альтернативы, пересказ кода |
| `docs/features/` | Фича | Модель, инварианты и границы возможности сервера — то, чего нет в коде | Перечни функций, тулов и переменных: они в коде и сгенерированных таблицах README |
| `docs/systems/` | Система | Контракт и поведение Moodle и других внешних систем | Наш код интеграции, кроме точки входа ссылкой |
| `docs/runbooks/` | Кейс | Реакцию на класс ситуации — ошибку тула, отказ сайта | Пошаговку под одну задачу |

В корне `docs/` лежат только словарь тегов `_tags.json` и шаблон `_template.md`. Новая папка
верхнего уровня заводится правкой этой таблицы и списка папок в `scripts/docs-atoms.mjs`.

Новый документ начинается с копии [шаблона](../_template.md), в которой остаётся скелет
разделов одного вида. Общие нормы атома, поля frontmatter и словаря тегов — глобальный скилл
`writing-doc-atoms`; здесь только проектное. Истории в атомах нет: она в `git log`.

Атом правится тем же коммитом, что и расходящийся с ним код. `AGENTS.md` и README ставят
на атом ссылку, а не пересказывают его.

## Почему

Знание о сервере, которого не видно из кода, — почему вход устроен так, что нельзя
нарушать, — иначе живёт в AGENTS.md и README и расходится с кодом. Проверку формы атомов
`npm run docs:check` делает в pre-commit, поэтому расхождение со словарём и битый путь
в `code:` не доходят до коммита.
