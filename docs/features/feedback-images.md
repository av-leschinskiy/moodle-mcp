## Как устроено

Параметр `images` у `moodle_save_grade` — локальные файлы, которые студент увидит внутри
текста отзыва. В html и markdown картинка ставится ссылкой `@@PLUGINFILE@@/<имя файла>`,
в plain и без ссылки — дописывается в конец отзыва. Имя в ссылке — имя файла на диске.

Порядок вызова: локальные проверки картинок и ссылок → проверка оценки по заданию →
`core_webservice_get_site_info` (разрешена ли загрузка, предел размера) → загрузка всех
файлов в один черновик → `mod_assign_submit_grading_form` с `itemid` черновика → чтение
сдачи обратно. Ответ тула называет каждую картинку и есть ли ссылка на её файл в
сохранённом отзыве. Без картинок запись идёт прежним путём, `mod_assign_save_grade`.

Механика Moodle, на которую это опирается, — [Файлы в отзыве-комментарии
Moodle](../systems/moodle-feedback-files.md).

## Инварианты

- **Читаются только явно переданные абсолютные пути** к обычным файлам; тип — PNG, JPEG,
  GIF, WebP и по расширению, и по сигнатуре; размер и число картинок ограничены
  константами в `src/utils/feedback-images.ts`.
- **Имя файла — латиница, цифры, `.`, `_`, `-`, без повторов.** Такое имя Moodle сохраняет
  без изменений и оно не требует кодирования в URL, поэтому ссылка в тексте совпадает с
  файлом. Если Moodle всё же сохранил файл под другим именем — отказ до записи оценки.
- **Ссылка `@@PLUGINFILE@@` на файл, которого нет среди картинок, — отказ** до любого
  запроса: иначе студент увидел бы битую картинку.
- **Ошибка загрузки любого файла обрывает вызов до записи оценки.** Черновик с уже
  загруженными файлами студент не видит.
- **Токен уходит в загрузку полем тела, не в URL**; ошибки загрузки проходят `scrub`.
- **Тул остаётся с подтверждением хоста** (`destructiveHint`), описание говорит, что
  студент увидит картинки.

## Почему так

- **Форма оценки вместо `mod_assign_save_grade`:** только она передаёт плагину отзыва
  `itemid` черновика, без которого файлы к отзыву не привязываются.
- **Предел размера — `upload_max_filesize` PHP по умолчанию:** меньше него сайт не примет
  ни при каких настройках Moodle, а снимок экрана в него укладывается. Файлы грузятся по
  одному, поэтому общий предел запроса `post_max_size` не задевается.
- **Проверка `uploadfiles` до загрузки:** отказ сервиса иначе пришёл бы как
  `accessexception`, который клиент по остальным функциям толкует как «войдите заново», а
  перелогин тут не помогает.
